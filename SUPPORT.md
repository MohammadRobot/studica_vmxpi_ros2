# Support scope

The project is currently a pre-production open-source platform. Community
issues may be used for reproducible bugs, documentation defects, and feature
proposals that do not disclose security information.

Every support request should include the package version or commit, dependency
manifest, Ubuntu and ROS version, robot profile, expected behavior, actual
behavior, and relevant redacted diagnostics. Avoid screenshots when text logs
are available.

Commercial support terms, response times, supported release lifetime, spare
parts, remote access, and end-of-life policy are not yet defined. They must be
published before a product is sold as supported.

Security and safety vulnerabilities follow `SECURITY.md`, not public issues.
